# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability in PensionSure, please do not disclose it in a public issue or discussion.

Instead, please report vulnerabilities confidentially through GitHub's [Private Vulnerability Reporting](https://github.com/srivarsan007/PensionSure/security/advisories/new).

Please provide:
- A description of the vulnerability and its potential impact.
- Steps or a minimal test case to reproduce the behavior.
- Any suggested remediations or mitigations.

You will receive an acknowledgement within 48 hours, followed by updates as the issue is assessed and patched.
